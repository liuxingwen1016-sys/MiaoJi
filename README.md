# 妙记账单 · 完全本地版

妙记账单是基于 **Vue 2 + uni-app + uView 2** 的轻量记账应用。本分支已移除微信登录、uni-id、uniCloud、云函数和订阅消息，所有功能无需账号、无需后端服务、无需网络即可运行。

本项目用于 MigBot-Lite 的 Vue 2 → Vue 3 及后续 HarmonyOS 转换试点。

## 本地版能力

- 账单：支出、收入、转账、修改、删除、按月查看
- 资产：多账户、余额、默认账户、隐藏账户、总资产统计
- 报表：月度收支、分类统计、图表展示
- 模板：保存常用账单模板并快速记账
- 秒记：将模板绑定到快捷记账入口
- 定时记账：应用启动或回到前台时自动补记到期任务
- 个人资料：昵称和头像保存在当前设备
- 本地建议：将培训或使用建议保存到当前设备

## 与原项目的差异

| 项目 | 原版 | 本地版 |
|---|---|---|
| 用户身份 | 微信登录 / uni-id | 固定本地用户，无需登录 |
| 数据库 | uniCloud 云数据库 | `uni.setStorageSync` 本地持久化 |
| 定时任务 | 云函数定时器 | 启动/回到前台时离线补记 |
| 消息通知 | 微信订阅消息 | 已移除 |
| 反馈 | 微信小程序反馈入口 | 本地建议备忘 |
| 网络依赖 | 需要云空间和微信配置 | 无 |

## 运行方法

1. 安装 HBuilderX。
2. 使用 HBuilderX 打开本项目目录。
3. 选择“运行到浏览器”进行 H5 调试，或选择“运行到手机或模拟器”生成 Android/App 版本。

不需要创建 uniCloud 服务空间，不需要配置微信 AppID，也不需要上传数据库表或云函数。

如需进行正式 App 云打包，请在 HBuilderX 中为 Fork 后的项目重新获取一个 uni-app 应用标识；该标识仅用于构建，不是业务后端依赖。

## 本地数据说明

业务数据统一保存在 `miaoji-local-database-v1` 本地存储项中，个人资料及少量界面缓存使用独立存储项。首次运行会自动创建一个余额为 0 的默认账户。

“我的 → 清除本地数据”可以恢复到首次运行状态。卸载应用、清除浏览器站点数据或使用该功能后，历史数据无法恢复。

定时记账无法在应用完全关闭时依赖服务器执行。本地版会在下次启动或回到前台时依次补记所有已到期任务，最多单次补记 365 次以防异常规则造成死循环。

## 主要目录

```text
components/              业务组件
pages/                   首页、账单、报表、我的
pagesAccount/            记账与资产编辑
pagesMy/                 模板、秒记、定时任务、个人资料
static/                  图片与图标
uni_modules/             保留的 UI 与图表依赖
utils/local-db.js        本地数据库兼容层
utils/local-cron.js      本地定时记账执行器
```

## 技术栈

- Vue 2
- uni-app（HBuilderX 项目）
- uView 2.0.36
- uni-ui
- qiun-data-charts

本地数据库兼容层保留了原项目常用的 `collection / where / orderBy / add / update / remove` 调用形态，便于培训中直观对比云端版与本地版，也减少了对业务页面的侵入。
